### 🚧 Dao Chronicle — Cultivation Tracker

A browser-based character sheet and campaign companion for a **xianxia** (Chinese cultivation fantasy) tabletop RPG. Players track their Qi and Soul cultivation, equipment, inventory, companions, Dao comprehensions, alchemy and quests; the DM manages the whole world from a separate admin console.

Fully bilingual (English/German), mobile-friendly, and deployed as a static site — no custom backend at all. Supabase (Postgres + Row Level Security) handles auth, data and storage straight from the browser, with database policies doing the authorization work a server would normally do.

**Frontend** · Vanilla JavaScript (ES2020+), Canvas API, hand-written CSS
**Backend** · Supabase — Auth, PostgREST, Storage
**Database** · PostgreSQL with Row Level Security
